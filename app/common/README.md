# Common 约定

`app/common/` 只放真正跨层复用的纯工具。

## 允许

- 只依赖标准库或基础第三方库。
- 不访问数据库、Redis、文件系统、网络或 LLM。
- 不读取 `settings`。
- 不包含业务领域名称和业务策略。
- 至少被两个不同层级复用后再迁入这里。

## 不允许

- 把 `app/db/`、`app/harness/`、`app/services/` 的局部辅助函数集中到这里。
- 创建没有明确语义的 `utils.py` 大杂烩。
- 通过 `common` 反向依赖上层模块。

当前没有强行迁入任何现有工具；领域语义优先留在其所有者模块。
